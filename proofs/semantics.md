# Finite policy semantics and certificates

These notes state the mathematical contract independently of the manuscript. They are mathematical proofs, not proof-assistant output. Executable finite checks test selected instances and implementations; they do not replace the universal arguments.

## 1. Objects and observations

Fix finite nonempty sets of principals U, resources O and actions A, a finite role set R, a static membership relation H contained in U × R, and a finite set B of named Boolean state variables. Let S = {0,1}^B and X = U × O × A. The initial state is s0 in S.

A policy has a finite set Z of typed references. Each z has a nonempty finite candidate set C(z) of the right entity sort. The set of complete bindings is the Cartesian product of all C(z). Every binding is fixed for the whole execution. Repeated occurrences of one reference use the same choice; different references may choose the same entity. There are no correlations or exclusions between different reference choices.

A rule has a conjunction of atoms, a decision in {allow,deny}, and an assignment map. Atoms compare an input field to a literal or a typed reference; test or negate principal/role membership; or test a named Boolean state variable. An assignment sets a bit to a constant, another old bit, or its negation. Different assignments have distinct destinations. Denying rules have no assignments. References occur only in guards, not in effect destinations or values.

Evaluate all guard atoms in the current state and request under the binding. The least matching rule index supplies the decision and effect. With no matching rule, return denial and the unchanged state. Every effect expression reads the same old valuation, so assignment order has no meaning. The resulting step function is F(P,beta,s,x) = (d,s').

A finite target M has states Q, initial q0, the same request alphabet X, total deterministic transition delta: Q × X -> Q, decision map dM, and an observation nu: Q -> S. The observation is not required to be injective. A trace records the initial valuation followed, for each request, by the decision and complete successor valuation. Inputs are compared pointwise as the same word. The observation is not a log of individual write events.

Uniform equivalence means: for every complete fixed binding beta and every finite input word w, source and target traces on w agree. Unioning the behaviors of different interpretations and then testing containment is a different, weaker question.

## 2. Determinacy and canonical representation

**Determinacy and preservation.** Every typed literal or reference evaluates in its declared domain. Atoms and finite conjunctions have unique truth values. A nonempty finite set of matching rule positions has one least element. Each assignment reads a defined Boolean value and destination uniqueness makes the simultaneous update a total function on exactly B. The default and every explicitly denying rule stutter. Thus F is total, deterministic, Boolean-state preserving, and denial-stuttering.

The surface language uses distinct keyword and quoted-name token classes. Identifiers are decoded JSON-quoted strings, interpreted with exact Unicode scalar-sequence equality. The executable envelope permits one through 256 scalar values while rejecting Unicode Cc/Cf controls and lone surrogates (Cs) in both the producer and standalone checker. Names are not case-folded or composition-normalized. The declaration phases and final `otherwise deny.` clause are syntactically explicit. Unsupported prose is a parse failure, not evidence of semantic ambiguity. Declared multi-candidate references, by contrast, have one parsed structure and several admitted fixed interpretations.

Normalization sorts finite domain declarations, the membership relation, state declarations, reference declarations and their candidate sets, and effect destinations. It does not reorder guards or rules. Its validity checks reject duplicate declarations, undeclared or ill-sorted names, repeated effect destinations, and denial updates. Declarations and membership denote sets, so their canonical order preserves meaning. State order is representational: named valuations are unchanged. Simultaneous assignments with different destinations commute as a map. Sorting an already sorted component leaves it unchanged. Hence normalization preserves semantics and is idempotent.

**Canonical parse/print law.** For every valid AST p, parsing its canonical printed text gives norm(p). The proof is structural. Quoting round-trips each permitted scalar sequence. Domain and declaration keywords uniquely identify their productions, with punctuation delimiting each finite list. Each guard atom retains its sort, literal-versus-reference tag and polarity. Each effect retains its destination and old-state expression. Rules retain their order. The printer's unique default terminator is consumed once at end of input. Induction over declarations, atoms, effects and rules therefore reconstructs precisely the normalized AST. Consequently, for every accepted text t, printing the result of parsing t, parsing it again and printing it again produces the same canonical text. This is normalization of syntax, not recovery of arbitrary original whitespace or wording.

The supported canonical sentence bound is four MiB. At most 96 domain names, 256 membership pairs, seven state declarations, sixteen references with at most 32 candidates each, and 256 rule/atom/effect nodes occur. Even charging two maximal names per node and four UTF-8 bytes per scalar, with quoting and punctuation, the canonical rendering is below two MiB. The four-MiB reader limit therefore does not exclude a supported canonical AST. Serialized target tables have a separate operational limit; mathematical compilation is not a promise that every table fits that transport limit.

## 3. Forward compilation and semantic reification

**Fixed-binding compilation.** Choose any bijection h from S onto a target-state set. Define nu(h(s)) = s, q0 = h(s0), and the transition from h(s) on x by F(P,beta,s,x) = (d,s'): its decision is d and its successor is h(s'). This construction preserves traces under the chosen beta. Initially nu(q0)=s0. At any prefix where q=h(s), the next target definition gives the same decision and observation and q'=h(s'). Induction proves equality for every finite word. The delivered compiler deliberately numbers states in reverse valuation order, so tests do not depend on equal source/target state identifiers.

Let Reach(M) be the states reachable by finite words. It contains q0 and is closed under all requests. A target can be represented by an alias-free source whose entire state is the declared valuation if and only if both of these conditions hold on Reach(M):

1. A denial transition preserves nu.
2. States with equal observations have equal next decision and successor observation for every input.

**Reification sufficiency.** The second condition makes T(s,x) = (dM(q,x),nu(delta(q,x))) independent of the choice of reachable q with nu(q)=s. For each allowing table cell, create an exact request-and-state guard and constant assignments for every destination bit. No other exact cell guard can match that cell. For a denying cell, create no allowing rule; default denial stutters, which equals the target post-state by condition 1. Initialize the source to nu(q0). This establishes one-step agreement on every reachable observation, whose successors are again reachable observations. Induction proves trace equivalence.

**Reification necessity.** Suppose such a deterministic source is trace equivalent. A word reaching each target q leaves the source at nu(q), because full post-state is observed. A target denial therefore stutters because source denial stutters. For two reachable states q,q' with the same observation, the source after either witnessing prefix has exactly the same state. Its next response to each request is identical. Equivalence transfers that identity to both target transitions, proving condition 2. An unreachable target row has no witnessing prefix and is not constrained by this behavioral argument beyond structural validity.

With v reachable observations and k bits, the construction has at most v|X|(4+2k) rule/atom/effect nodes: one rule, three request tests, k state tests and k assignments per allowing cell. This proves existence in the uncapped grammar, not minimum source size or success under the 256-node implementation envelope. Reifying a compiled fixed-binding policy and recompiling the result preserves behavior when this envelope is met. It need not preserve source rule structure, references or wording.

## 4. Local reference support

At a fixed (s,x), call a rule concretely viable when all of its atoms that contain no reference are true. Let D(P,s,x) contain every reference occurring in every concretely viable rule. Do not use binding-dependent priority to prune this set.

**Support sufficiency.** If beta and gamma agree on D, then F(P,beta,s,x)=F(P,gamma,s,x). A nonviable rule has a false concrete conjunct under both bindings, so it cannot match either. In a viable rule, all reference occurrences are in D and have identical values under the two bindings; all concrete atoms also agree. Thus every guard has the same truth value. Both interpretations select the same least matching rule or both select default denial. The selected effect reads only the common old state and is reference-free, so both complete results agree.

This proof depends on conjunctive guards and on reference-free effects. Merely finding a false concrete disjunct would not justify discarding a disjunction. Effects with reference-dependent destinations or values would require enlarging the support.

Choose a fixed filler binding beta0. Any assignment alpha to D extends to a complete binding alpha-hat by using beta0 outside D; this is valid because the binding space is a Cartesian product. A proposed cell output y agrees for every complete binding if and only if it agrees for every such local assignment extension. The forward direction is specialization. For the reverse, restrict an arbitrary complete beta to D, use the local hypothesis for alpha-hat, and transfer the equality to beta by support sufficiency.

## 5. Closed-state certificates

A certificate is a finite set C of target state identifiers. Check structural validity, then the following obligations:

- q0 is in C, and delta(q,x) is in C for every q in C and x in X.
- nu(q0)=s0.
- For each q in C, x in X and assignment alpha to D(P,nu(q),x), the source step under alpha-hat equals (dM(q,x),nu(delta(q,x))).

**Soundness.** Fix any complete beta. The initial equality establishes the invariant that the source state equals nu(q), with q in C. At a matching prefix, local quantification supplies equality of the next source output under beta and target output. Closure keeps the next target in C, and equality of the post-valuations restores the invariant. Induction proves equality of all traces under this fixed beta. Because beta was arbitrary, equivalence is uniform. No runtime reselection of a reference is used.

**Relative completeness.** Suppose uniform equivalence holds. Choose C=Reach(M), which contains q0 and is closed. The empty word gives initial equality. For any q in C choose a word w reaching q. For any complete beta, equivalence on w reconstructs the source state as nu(q). Equivalence on wx gives cell agreement for each next request x. This holds for every beta and therefore for all local assignment extensions. Thus C passes. Relative completeness asserts that a passing certificate exists; an unnecessarily large closed superset can fail at an unreachable state even for equivalent initial behavior.

The certificate needs O(|Q| log |Q|) bits for state identifiers, but its verification may be exponential in reference width. If b bounds candidate-set size and w bounds |D(P,nu(q),x)| on C, the exact number of source binding evaluations in a successful semantic check is

    sum over q in C and x in X of product over z in D(P,nu(q),x) of |C(z)|,

which is at most |C||X|b^w. Empty support contributes one evaluation. Structural validation, support discovery, source evaluation and representation allocation have additional polynomial costs. The explicit target can already be exponential in the number of source bits.

A bounded implementation reports resource-inconclusive before exceeding its enumeration envelope. That outcome is not rejection of the ideal predicate, and relative completeness does not promise that an unlimited finite input fits a fixed operational budget.

## 6. Globally shortest distinguishing traces

Assume initial observations match. A cell (q,x) is bad if some complete binding disagrees with the proposed target output at source state nu(q). Let d be the least target-graph distance from q0 to a state having a bad cell. All cells at target-state distance less than d agree universally.

**Prefix reconstruction lemma.** Under those passing shallower cells, every word of length at most d has equal source/target traces under every binding. Induct on the request position i. The preceding target state is reached by i<d requests and therefore has shortest distance at most i. Its cell passes under the same chosen complete binding. It matches the next decision and restores source state = nu(target state). Initial equality starts the induction.

Choose a first bad cell at breadth-first distance d, a shortest stored word w reaching its state, and the complete filler extension beta of its failing local assignment. Prefix reconstruction applies to this very beta and brings its source execution to nu(q) after w. The next request x genuinely differs. Thus wx is a valid length d+1 counterexample under one fixed complete interpretation, not a splice of unrelated local choices. Every shorter word has length at most d and agrees under every binding by the lemma. The witness is globally shortest across all bindings and all words.

A shortest target path has no repeated state: removing a repeated-state cycle would leave its endpoint unchanged and shorten it. Its length is at most |Reach(M)|-1. Hence the distinguishing word has length at most |Reach(M)|. Initial observation disagreement instead gives an empty witness of length zero.

**Tightness.** For any n, use n distinct bit valuations and one request. The source allows while advancing through a chain of n states, then allows and stays at the last. The target agrees on the first n-1 transitions, then denies and stays. Its n states are reachable, and the first difference is exactly request n. Exact-valuation guards and constant assignments express this source. The compact executable counter fixtures for powers of two reset the last source state instead; that different final effect still gives the same first divergence at request n.

**Decision-only boundary.** Give the source a counter that allows for n-1 requests and then denies, and compare with a one-state always-allow target while observing decisions only. The shortest difference is n, while the target size is always one. For arbitrary n, this refutes every witness bound that depends only on target-state count for decision-only observation. It does not refute the usual product-state bound.

## 7. Ambiguity and complexity

An interpretation-independent target exists if and only if all complete bindings induce the same input-indexed traces. Necessity follows by transitivity of equality through a common target. For sufficiency, choose one binding, compile it, and use the assumed equality to every other binding. Having exactly one candidate per reference is sufficient, but not necessary. Complementary role tests leading to identical effects give explicit multi-candidate uniform policies.

For a fixed cell, let E be the references for which two bindings differing only at that reference can change the complete cell result. In a Cartesian binding space E is a sufficient support: two bindings agreeing on E can be connected by changing each outside reference one at a time; each change preserves the result by nonessentiality. Any sufficient support must contain E because an essentiality pair disagrees on no other coordinate. Thus E is the unique smallest support, and E is contained in D by support sufficiency. This semantic dependence principle is established in the variable-independence literature; its use here is specialized to the complete policy-step function.

The Cartesian condition is necessary for that coordinate argument. On the correlated admissible bindings {00,11}, no two admissible bindings differ at only one coordinate, so both coordinates appear nonessential by that definition. A function returning the shared bit nevertheless differs between the two admissible bindings. Our syntax does not admit such correlated candidate restrictions.

**Uniform equivalence is coNP-complete in the uncapped grammar with an explicit target table.** Non-equivalence has a polynomial witness: a complete binding and a request word of length at most the number of reachable target states (or the empty word). Simulation checks it in polynomial time in explicit input size. For hardness, reduce CNF unsatisfiability. Encode each Boolean variable by a binary role reference and a principal belonging to one of its two candidate roles. For each CNF clause, add an allowing rule whose conjunction is exactly that clause being false; default deny. Use no state and one request. Against the one-state always-allow target, uniform equivalence holds exactly when every assignment falsifies some clause, namely when the CNF is unsatisfiable. Empty clauses become unconditional allowance; an empty clause set leaves default denial. The construction is linear in clause-literal count. Consequently the complement is NP-complete and uniform equivalence is coNP-complete.

**Exact reference relevance is NP-complete.** Membership is witnessed by two complete bindings differing only at the named reference and giving different results. For hardness, use the same clause-falsity tests as denying rules, followed by an allowing rule guarded by a fresh binary reference z. If a clause is false, the output is deny regardless of z. If the formula is true, the output equals the truth of z. Therefore z is relevant exactly when the original CNF is satisfiable. The tests exhaust the finite two-variable reduction families but do not establish the unbounded hardness proof by enumeration.

Constant implementation bounds do not have these asymptotics. They are resource envelopes for experiments in the uncapped parameterized language, not a new complexity class.

## 8. Symbolic cell checking

A reduced ordered finite-domain decision diagram has one level per reference, with one outgoing edge per candidate, and terminal values that are either Booleans or exact decision/post-state pairs. Equal-child nodes collapse to that child; equal level/child tuples share a node. Type-tagged terminals distinguish Boolean atoms from complete outputs.

For a fixed state and request, each literal or state atom is constant. A reference atom is a node whose candidate edges contain the corresponding truth values. Conjunction is built by conditional composition. Each rule's effect is a constant complete result at the fixed old state. Fold rules from last to first using `if guard then selected-result else later-result`, starting from default denial. Induction on atoms, conjunction and the reverse rule list shows that evaluating the diagram at any complete binding yields exactly F(P,beta,s,x).

Reduction preserves evaluation because all alternatives of an equal-child node already give the same value; sharing identical subfunctions changes no path result. A cell passes if every reachable terminal is the proposed output. A differing terminal path supplies a consistent partial binding, completed with arbitrary candidates at unused levels. This is a legitimate complete witness by the Cartesian contract. Feeding these cell decisions to the same breadth-first target criterion gives the same uniform and shortest-witness properties. Symbolic sharing may eliminate references that conservative concrete support retains; there is no claim that local enumeration dominates decision diagrams.

## 9. Public projection and evidence scope

The consumed model examples use literal equality, static role reachability, conjunction and the explicitly identified combining rules. In a model without request-to-request equality, an entity name absent from all policy constants and role-graph endpoints has the same truth values for every relevant atomic test as any other such absent name. One fresh unlisted representative per field therefore suffices for that finite outside-name class. This is not a projection theorem for arbitrary Casbin matchers.

Basic literal rows become conjunction guards. Role reachability is materialized as the static membership table. In the deny-overrides model, put all denying matches before allowing matches; the result is allowance precisely when some allow matches and no deny matches. Priority uses source row order. Resource-role reachability is expanded into adjacent literal resource cases with the same decision and priority position. A domain request embeds principal/domain and resource/domain pairs injectively as names, and qualifies the role names with the domain. Matched-domain requests preserve the source predicates. Cross-domain combinations in the target product alphabet are a declared denying extension, not native four-field source requests.

The separate model interpreter traverses the original role graph rather than reusing the materialized membership semantics. Its agreement on 516 projected requests and 40 frozen source assertions is bounded adapter evidence. The upstream engine is not executed, and the source renderings are not claimed byte-identical to upstream downloads. The constructed one-use and parity variants deliberately add state and are not attributed to the public models.

## 10. Reading the finite checks

The 10,000 primary case records, 3,330 original auxiliary records, 592 derived-construction records, 1,024 adversarial records, 23,040 complete tiny-domain source--target pairs, and 52 pilot records have different roles. Public-derived cases exercise conversion and its constructed stateful variants. Deterministic generated ASTs test semantic paths and include duplicate structures whose counts are reported. Width cases isolate local versus global reference enumeration; global work beyond eight aliases is derived rather than executed. Chain cases check minimum witnesses through length 128. Invalid-evidence and resource controls test status distinctions.

A replayed counterexample proves disagreement for its concrete input. A bounded word search that finds nothing proves only the absence of a witness within that depth; it is never used as the general equivalence certificate. Product reachability gives an exact finite check when completed. Internal agreement of independently structured components can expose faults but is not an independent external review or a formal proof that their entire implementation is correct.


## 11. Canonical observable realization

This result uses the reachable-fiber condition of Section 3. Write V for the set of observations nu(q) with q in Reach(M). If any two reachable states with the same observation give the same decision and successor observation on every request, then T(s,x) = (dM(q,x), nu(delta(q,x))) is well defined for s = nu(q). Define the observable quotient to have state set V, initial state nu(q0), identity observation, and transition/decision given by T.

**Proposition (canonical observable realization; manuscript prop:quotient).** The quotient has exactly V as its reachable state set and has the same complete traces as M. Among deterministic state-observing machines over the same alphabet with those traces, |V| is the minimum reachable-state count. Every minimizer is isomorphic on its reachable part to this quotient, through its observation map. Denial stuttering is additionally necessary for reification into the particular policy grammar; it is not needed just to form the observational quotient.

**Proof.** A step from a reachable q maps to the quotient step from nu(q) by definition of T. Starting at the matching initial observation, induction over every word proves trace equality and that the quotient endpoint is the observation of the original endpoint. Thus every quotient-reachable state belongs to V, and every element of V is reached by a word witnessing the corresponding original state. Any equivalent state-observing machine must realize every value in V on such a word. One state has only one observation, so at least |V| reachable states are required. If that bound is attained, its observation map is a bijection to V. For a word reaching one of its states, equality on the word and each one-request extension forces its decision and successor observation to equal T. The bijection therefore preserves the initial state and all labeled transitions. This is the required isomorphism.

The result minimizes observable machine states, not policy sentences, rule counts, encodings, or checker running time. The companion reference module constructs this quotient after checking reachable-fiber coherence. Its 128-case finite family includes 112 coherent targets, 16 incoherent targets, and 16 coherent targets whose two reachable states collapse. The main certificate diagnostic does not minimize its input table before searching it.

## 12. Failure profiles for individual fixed bindings

Assume initial observations agree. For each reachable target cell c = (q,x), define E_c to be the set of complete bindings beta for which F(P,beta,nu(q),x) differs from (dM(q,x),nu(delta(q,x))). Local-support sufficiency says that membership in E_c depends only on beta restricted to D_P(nu(q),x). Thus E_c is a cylinder over this local assignment space, not a choice to be made anew during execution.

Let ell(beta) be the minimum length of any distinguishing word under beta, with infinity if there is none. Define h(beta) as the minimum of dist(q)+1 over cells whose E_c contains beta, again infinity for an empty set.

**Theorem (binding-wise shortest-failure characterization; manuscript thm:profile).** For every complete fixed beta, ell(beta) = h(beta).

**Proof.** If h(beta) is finite, select a bad cell at minimum distance and a shortest target word w to its state q. Every proper transition of w starts at a state whose target distance is strictly less than dist(q). Its cell is therefore good for this same beta. Starting from the common initial valuation, induction along w shows that the source reaches nu(q) and has matched the target so far. Appending x now distinguishes, so ell(beta) <= h(beta). Conversely, any word shorter than h(beta) visits a cell at its ith request whose target-state distance plus one is at most i, hence strictly below h(beta). Each such cell is good for beta. The same induction proves equality along that whole word, giving ell(beta) >= h(beta). When no bad cell exists, the induction applies to every finite word and both sides are infinity.

For n = |Reach(M)|, set H_0 empty and, for 1 <= j <= n, let H_j be the union of E_(q,x) over dist(q) < j. Exactly the bindings in H_j \ H_(j-1) have minimum distinguishing length j. The bindings outside H_n agree on all words. These assertions follow from the theorem and the bound dist(q) <= n-1. If initial observations do not agree, every binding instead has the empty-word witness. A cell that is bad for beta at a larger distance need not itself be source-reachable under beta after beta has already diverged.

**Analytic example (manuscript tab:profile).** Use one principal belonging to r and not t, one resource, actions a and b, a bit p initially false, and two references z_a,z_b with candidates {r,t}. The first rule allows a when p is false and membership in z_a holds, setting p true. The second allows b when p is true and membership in z_b holds, setting p false. Other requests deny and keep state. The target implements these two phases without role tests. E_(q0,a) consists of bindings with z_a=t; E_(q1,b) consists of those with z_b=t; its two other cells have empty failure sets. The four binding profiles are (r,r): infinity; (r,t): 2 with word ab; (t,r): 1 with a; (t,t): 1 with a. Exhaustive cell evaluation needs 2+1+1+2=6 local assignments instead of 4*4=16 complete-binding cell evaluations. These are direct symbolic calculations, not extra experimental cases or product-search timings.

The main diagnostic finds one shortest uniform witness. The companion profile routine constructs the complete finite classification by scanning target layers for each explicitly enumerated binding. Across 128 generated policies it classifies 296 bindings; singleton fixed-binding products agree with every verdict and shortest length. This finite agreement supports the implementation, while the theorem supplies the unbounded mathematical statement.

## 13. Observation-dependent witness bound

**Corollary (observable-quotient witness bound; manuscript cor:quotient-bound).** If reachable observation fibers are coherent, then for every fixed binding the shortest distinguishing length against M equals that against its observable quotient. Consequently, a failed uniform equivalence has a shortest witness of length at most |nu(Reach(M))|, with the empty word allowed for initial disagreement. This bound is tight.

**Proof.** Section 11 proves equality of the two target traces on every word. The sets of words distinguishing any chosen source binding from either target are therefore identical. The quotient has exactly |V| reachable states, so Section 12 gives the bound when initials agree. The original tight chain family has injective observations and first disagreement at |V|; it also establishes tightness of this smaller bound. The empty word handles initial disagreement independently.

Coherence is indispensable for this quotient: equal observations with different outgoing observable behavior cannot be merged by T. The original target-state bound still applies without coherence. The executable quotient construction is checked for trace equality on the finite two-state family, but the main diagnostic still searches the supplied target and no runtime improvement is claimed.

## 14. Dependency-closed observation projection

Let K be the selected state outputs and G the set of all state bits appearing in any guard, including unreachable rules. Add an edge c -> b whenever an effect assigns b := c or b := not c. Let J be the least set containing K union G and closed backwards along these edges: if b belongs to J and c -> b, then c belongs to J. All sets are finite, so repeated inclusion terminates. Constants add no incoming dependency. This is a syntactic closure, not a claim of minimum semantic relevance.

The projected policy P|J retains the full interface except that Boolean declarations and initial state are restricted to J. It retains every guard, reference, rule decision and rule order, deleting only assignments to destinations outside J. A now-empty allowing update remains allowance with an unchanged state. All guards remain well typed because G is included. Every retained old-state read stays in J by closure.

**Lemma (step projection; manuscript lem:step-projection).** If s restricted to J is u and F(P,beta,s,x) = (d,s'), then F(P|J,beta,u,x) = (d,s' restricted to J).

**Proof.** Every concrete request or role test sees the same input and static membership; every reference test sees the same beta. Every state guard bit lies in J and therefore has the same truth value. The ordered guard list selects the identical first matching rule, or default denial. The decisions agree. Denial leaves both states unchanged. For allowance and any b in J, an unassigned b keeps its old value in both policies; a constant assignment has the same constant; a copy or negated copy reads a bit c in J, whose old value agrees. Thus all retained destinations agree after the simultaneous update. No argument reads a partially updated value.

**Theorem (trace projection and inherited certificates; manuscript thm:projection).** For every fixed binding and word, the trace of P|J equals the trace of P with each valuation restricted to J, retaining the decisions. A candidate M_J that exposes the entire J-valuation can be checked against P|J by the original local certificate, with soundness, relative completeness and a shortest-witness bound of |Reach(M_J)| for this projected trace relation.

**Proof.** Initial restriction agrees by construction. Induct on word length using the step-projection lemma. This proves the trace identity for every fixed beta. P|J is again a well-formed policy in the same mathematical grammar. Applying the existing certificate and witness theorems to that policy and to the complete J-observation of M_J gives the remaining claims. They concern projected traces; they do not assert preservation of omitted coordinates or decisions for an arbitrary source transformation.

Deleting only outputs without checking dependencies is not justified. A retained destination that copies a hidden bit would read an unrepresented old value. Dropping a rule whose update becomes empty would change decisions or priority. Keeping G can retain a state bit even when a more semantic analysis could eliminate it. The reference pass computes this syntactic closure and filters declarations and destinations. On 192 policy/required-set pairs, 10,224 exhaustive full-state/request/binding tuples satisfy the one-step equation; 152 pairs discard at least one bit. These are semantic cross-checks, not a memory, privacy, or performance measurement.

## 15. Exactly restricted binding families

The original grammar and executable checker have Cartesian bindings. For a mathematical restriction, fix any nonempty Gamma subset of those complete bindings before checking. At a target cell c, use exactly A_c^Gamma = { beta restricted to D_c : beta in Gamma } as its quantified local assignments. Evaluation may use any Cartesian extension of such an assignment: local support makes its cell result equal to that of every legal extension, and at least one legal extension exists by this projection's definition.

**Proposition (restricted-family checking; manuscript prop:restricted).** The original structural, initial and closure obligations together with these projected cell obligations imply trace equality for every beta in Gamma. Conversely, such equality makes Reach(M) a passing certificate. With matching initial observations, failure has a shortest admitted witness of length at most |Reach(M)|; the cumulative failure sets are H_j intersect Gamma, with exact strata (H_j \ H_(j-1)) intersect Gamma.

**Proof.** For soundness, choose any beta in Gamma. At each cell its restriction belongs to A_c^Gamma. Equality for the chosen extension transfers to beta by local support. The original trace reconstruction induction then applies with beta fixed. For completeness, choose a reachable q, a request, and any projected assignment alpha. Choose a legal extension beta in Gamma and a target word reaching q. Trace equality for beta places its source at nu(q); equality on the one-request extension supplies the cell equation. Local support transfers it to any extension used in the check. Reachability supplies closure. Finally Section 12 is an individual-binding theorem, so restricting its domain to Gamma preserves its identity and gives exactly the intersected latency classes and bound.

For counterexample replay the extension must be a member of Gamma, unlike an arbitrary Cartesian extension sufficient for a single evaluation. One could retain a legal extension witnessing each projected assignment. Computing exact projections of a compact logical constraint may itself be difficult; no polynomial complexity result is inferred.

For example, two references with candidates {r,t} can select an always-allow behavior when both role tests are true or both are false, but denial when just one is true. With one principal belonging to r and not t, Gamma = {(r,r),(t,t)} matches an always-allow target, whereas the full Cartesian family does not. This does not restore the least-essential-coordinate theorem on correlated domains: paths that change one coordinate can still leave Gamma. The delivered grammar and main checker remain Cartesian. A companion checker accepts an explicitly listed family, deduplicates its support projections, and retains a legal family member for a mismatch; all 15 nonempty subfamilies of the four-binding example agree with singleton-product verdicts.

## 16. Switching closure and its observation premise

**Proposition (manuscript prop:switching).** Let M be total and deterministic and expose the entire policy valuation, including the initial value. Uniform equality of M with every fixed binding is equivalent to equality with every run that can choose a fresh admitted binding at each request.

**Proof.** Switching equality implies fixed equality by choosing a constant sequence. Conversely, relative completeness yields the reachable target set as a passing certificate. Local-support lifting makes its cell equation hold for every complete binding. Induct along a switching run: the initial state is nu(q0); if the current state is nu(q), the equation at (q,x) holds for the binding chosen now and returns the target decision and nu(delta(q,x)). No equality between current and earlier bindings is needed. The same induction handles every finite prefix and therefore every finite trace. The empty trace uses initial equality.

Fixed binding is not necessary for positive preservation once full-state uniformity holds. It remains the declared language convention and is essential to the meaning of per-binding failure profiles. Before acceptance is established, mixed local failures need not form a run of any one interpretation.

**Decision-only separation.** Let b initially be 0. There is one principal, resource and action; the principal is in role r and not role t; z has candidates {r,t}. The first rule tests membership in z, allows and assigns b:=1. The second rule tests b=0 and allows without change. The default denies without change. Fixed z=r always uses rule one; fixed z=t always uses rule two. Both fixed decision traces are all-allow. The switching choices r then t yield allow then deny because the first step makes b=1. They therefore differ from a one-state always-allow target. With complete post-state observations the two fixed interpretations disagree at the first step, so the proposition's premise fails. The extension campaign executes this example: both fixed decision-only products agree with the always-allow target, while switching search returns the two-step choices r then t.

The proposition is a consequence of the one-step invariant. The executable switching search is an exact finite search rather than a proof extraction: on 128 generated full-state candidates its verdict agrees with fixed-binding uniformity, and the decision-only control separates the two notions.


## 17. Interpretation classification

Let G_M be the set of complete bindings beta for which P_beta and M agree on every input word. When initial observations match, the binding-distance theorem identifies G_M with the complement of the final cumulative failure layer H_n, where n is the reachable target-state count. An initial mismatch makes G_M empty.

There are exactly three cases: all bindings belong to G_M; G_M is nonempty and proper; or G_M is empty. The first is uniform correctness. In the second, choose beta in G_M and gamma outside it. Some word separates P_gamma from M, and therefore also from P_beta, establishing source nonuniformity. The last case says that M implements no admitted interpretation; it does not decide source uniformity. For any admitted family Gamma, uniform agreement holds exactly when Gamma is a subset of G_M. Hence, when nonempty, G_M is the unique greatest such family.

If M is the correct compilation under beta_0, the compilation theorem puts beta_0 in G_M. A negative uniform result then forces the nonempty proper case. By contrast, an alias-free always-deny policy and always-allow candidate realize the empty case without reference ambiguity. These arguments classify the semantics. The companion profile routine reports the finite matching family and its latency strata; it does not permit silently restricting an original requirement after observing its failures.
