# Assumption and Counterexample Catalog

This catalog is a reviewer-facing map from each material premise to the failure mode that appears when it is removed. It summarizes constructions already formalized or exercised by the manuscript and artifact; it is not an additional empirical population.

| Premise or distinction | What fails without it | Small witness shape | Artifact check |
|---|---|---|---|
| Initial observations agree | A transition-only search can miss the globally shortest disagreement. | Source initial valuation differs from the target's initial observation; the distinguishing word is `ε`. | The diagnosis returns length zero, an empty request trace, and zero transition evaluations. |
| The certificate state set is transition-closed | Passing cells inside a listed set says nothing about an omitted successor. | Initial state passes locally but one request exits to an unchecked state whose next behavior differs. | Structural validation rejects non-closed evidence before semantic acceptance. |
| One complete binding is fixed along a source execution | Local failing assignments cannot in general be concatenated into one semantic interpretation. | Two cells fail under incompatible alias choices. | Witness construction extends the earliest failing local choice to one complete binding and replays every prefix. |
| Full post-state, or a proved sufficient quotient, is observed | Target distance alone need not bound a decision-only distinguishing trace. | A hidden counter/one-use bit delays the first decision disagreement while the visible target state repeats. | The decision-only control family separates decision equality from hidden-state equality. |
| Equal observed target states have equal observable successors | Reverse construction is not a function of the observation. | Two reachable target states share an observation but produce different decisions or next observations on one request. | Quotient/reification checks reject incoherent fibers. |
| Effects are simultaneous | Rule order inside an update list can change behavior and invalidate the stated step equation. | A rule updates `b := c` and `c := b`; sequential execution differs from simultaneous swapping. | Direct and compiled evaluators use the old valuation for every right-hand side. |
| Denial stutters the policy valuation | A default-deny step can silently mutate source state although the target records no authorized rule effect. | No guard matches, but an implementation flips a bit. | Source typing enforces empty deny effects; semantic cell comparisons and reachable-state reification check target denial-state preservation. Structural target validation alone does not establish it. |
| References excluded from a local support are semantically irrelevant to that cell | Enumerating only a syntactic subset could miss a binding-dependent result. | An omitted alias occurs in a concretely viable rule. | The support construction retains every reference in each viable rule and the essential-coordinate result states the exact but harder alternative. |
| Resource exhaustion is not semantic rejection | A hard instance can be falsely reported as inequivalent merely because enumeration stopped. | A wide alias product exceeds the declared cap before all obligations are evaluated. | All bounded interfaces return `inconclusive`; preflight and streaming limits prevent unbounded materialization. |
| Reachability is separated from arbitrary closed supersets | An unreachable mismatch can make a closed superset fail even though traces from the initial state agree. | Add an unreachable state with a wrong observation or transition. | Relative completeness is stated for the actual reachable set, not every closed superset. |
| Unicode control and format categories are rejected | Visually deceptive or bidirectionally reordered identifiers can cross the human review boundary. | Names containing DEL, C1, or a bidi control. | Producer and checker reject `Cc`, `Cf`, and `Cs`; ordinary non-ASCII identifiers remain valid. |

The catalog does not claim that every premise is logically necessary for every weaker theorem. It identifies why each premise is present in the stated certificate, witness, reification, or implementation contract.
